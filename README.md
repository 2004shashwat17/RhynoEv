⚡ Rhyno EV – Electric Vehicle Buying Platform
🚘 Rhyno EV is a modern, responsive React.js web application designed during my summer internship for Rhyno EV, a company focused on promoting sustainable mobility through electric vehicles. This platform provides users with a smooth experience to browse, filter, and learn about Rhyno’s electric scooters and the broader EV ecosystem.

🔗 Live Site → https://rhynoev.netlify.app/

📌 Features
🛒 EV Product Listing
Showcases Rhyno EV’s electric scooters

Clean product cards with image, specs, and pricing

🔍 Sort by Price – High-to-low or low-to-high for buyer flexibility

📈 EV Future & Blogs
Informative blog section on:

The future of electric vehicles

Benefits of EV adoption

Charging infrastructure, maintenance tips, and more

Educates customers beyond just products

🖥️ Responsive UI
Built using React.js

Styled with React Bootstrap for a modern and mobile-first design

⚡ Performance + Hosting
Deployed on Netlify for fast, reliable, and global access

Optimized assets for fast loading and smooth navigation

🛠️ Tech Stack
Layer	Tech Used
Frontend	React.js
Styling	React Bootstrap
Deployment	Netlify

🚀 Getting Started (Local Setup)
# Clone the repository
git clone https://github.com/your-username/rhyno-ev.git

# Run locally
